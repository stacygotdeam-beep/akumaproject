# Как включить вход через Discord

Эта сборка не подключена к хостингу и без настройки не позволит войти в обычном режиме. Тестовый режим `Akuma.exe --demo` работает без сети и не сохраняет данные.

## 1. Сначала сбросьте раскрытый токен

Откройте Discord Developer Portal → приложение бота → Bot → Reset Token. Старый токен больше не используйте. Новый токен и OAuth2 Client Secret не отправляйте в чат, не добавляйте в исходники, GitHub или EXE. Они вводятся только в секретные переменные хостинга.

## 2. Создайте веб-сервис Render

1. Загрузите папку `auth-server` в GitHub-репозиторий и создайте в Render сервис типа Web Service из этого репозитория. Если репозиторий содержит все исходники Akuma, укажите Root Directory `auth-server`; если он содержит только содержимое папки auth-server, корень оставьте пустым.
2. Выберите Node, Build Command: `npm install`; Start Command: `npm start`. Render выдаст адрес вида `https://НАЗВАНИЕ.onrender.com`.
3. В Discord Developer Portal → OAuth2 → Redirects добавьте точный адрес `https://НАЗВАНИЕ.onrender.com/oauth/callback`. Убедитесь, что бот добавлен на сервер Akuma и у приложения включена подходящая установка для пользователей.
4. В настройках Environment на Render добавьте:
   - `PUBLIC_URL` — адрес Render без завершающего пути, например `https://НАЗВАНИЕ.onrender.com`.
   - `DISCORD_CLIENT_ID` — Application ID приложения Discord (не ID сервера).
   - `DISCORD_CLIENT_SECRET` — OAuth2 Client Secret из Discord Developer Portal; секрет.
   - `DISCORD_BOT_TOKEN` — новый токен бота после сброса; секрет.
   - `DISCORD_GUILD_ID` — `1558780910634147892`.
5. Перезапустите сервис. Откройте `https://НАЗВАНИЕ.onrender.com/health`: должен появиться ответ `{"status":"ok"}`.
6. Рядом с `Windows/Akuma.exe` откройте `auth-server.txt`, удалите его содержимое и оставьте одну строку: `https://НАЗВАНИЕ.onrender.com`. Без кавычек, слэша, токенов и паролей. Сохраните. Так же настройте этот файл в сборке перед распространением.

## 3. Проверьте

Войдите через Discord участником сервера; проверьте имя и кнопку Sign out в Settings. Затем проверьте вход аккаунтом, которого нет на сервере: должно появиться приглашение; после вступления нажмите Check again. Проверьте выход и повторный вход. Сессия не сохраняется после закрытия Akuma, и после перезапуска сервиса может понадобиться вход заново. При недоступности проверки активные очереди останавливаются.

Бесплатный Render может «засыпать»; первый вход после простоя может занять около минуты. Код протестирован с имитацией Discord и через Wine, но реальный Discord OAuth, Render и настоящая Windows требуют отдельной проверки до публикации. Изменённый пользователем EXE может обойти локальное ограничение: серверные функции должны независимо проверять права доступа.
